# Contributing to EQLSaK

Thank you for helping make the companion more useful and accurate.

## Good contributions

- Correct EQL-specific routes, commands, quests, drops, vendors, and NPC locations with a source or reproducible observation.
- Improve keyboard, touch, screen-reader, and low-powered-device support.
- Improve the 3D viewer without presenting approximate geometry as a game-exact reconstruction.
- Add tests and release checks that prevent regressions.

## Before submitting a change

1. Explain what changed and why.
2. Include evidence and the correct provenance label for game information.
3. Confirm that you have permission to contribute every added asset.
4. Run the checks listed in README.md.
5. Do not include personal logs, credentials, build archives, or generated dependency folders.

By contributing, you agree that your code contribution may be distributed under the project's MIT License. Assets and datasets must include an explicit compatible license or permission statement.

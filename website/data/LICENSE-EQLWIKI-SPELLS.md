# EQL Wiki spell data attribution

`eqlwiki-spells.json` is adapted from the class spell tables maintained by the
[EverQuest Legends Wiki](https://eqlwiki.com/Category:Spells). The wiki's
original text is licensed under the
[Creative Commons Attribution-ShareAlike 4.0 International License](https://creativecommons.org/licenses/by-sa/4.0/).

The generated dataset is distributed under the same CC BY-SA 4.0 terms. EQLSaK
records the source page for every row and links players back to the corresponding
wiki spell page. The sync script performs formatting and normalization only; it
does not claim that every community-maintained value has been verified in game.

Spell-category sigils rendered by EQLSaK are original interface artwork and are
not copied from EverQuest, Daybreak, or EQL Wiki image assets.

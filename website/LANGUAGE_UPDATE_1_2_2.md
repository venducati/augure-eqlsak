# Clearer guide and app text — 1.2.2

The installation guide and Build Advisor now use shorter sentences and plain words, aimed at an eighth-grade reading level. The guide keeps its color highlights. The advisor keeps the same mural, panels, and icons.

The update covers class choices, goals, score details, class strengths and tradeoffs, buddy advice, zone advice, source summaries, rule updates, and Combat Meter notes. A short glossary explains terms such as DPS, CC, MCE, buff, and faction. Source labels and source links remain in place.

Build scores, class ratings, rule conditions, and saved build choices are unchanged. This update does not recheck game facts or claim that old sources are now current.

## Saved rules

When older saved rules load, the app refreshes text that exactly matches its old built-in wording. It keeps custom text, points, conditions, IDs, and source links. The matching text is listed in data/advisor-language.json. The refresh code is in lib/advisor-wording.ts.

Edited and downloaded rule files may have their own writing style. Text from source websites is shown as written by those sites.

## Files to use

- Install EQLSaK-Build-Advisor-1.2.2-Setup.exe on Windows 64-bit.
- Open EQLSaK-Offline-Advisor.html in a browser for the single-file version.
- Open Windows-Advisor-Guide.html in a browser to read the guide with its color highlights.

The installer remains unsigned. This update does not publish changes to the live EQLSaK website.
